## Li Factor + Separate + eRidge

The verified 173 upper-bound hits come from 1,152 scored releases (16 windows × 72 each): four datasets, two backbones, both windows, run 42. Of the 173 hits, 109 occur on M5 and 64 on Wiki2. Both Labour early windows were added retrospectively to the original 14-window grid; neither contains an upper hit. The author repository pinned at a2ba86f568b710aeb3411d46f94b3c70f5e55833, main_experiment.R around lines 500–516, specifies the 80/20 residual split and a 26-point ridge grid, 0 plus 10^(-1),10^(-0.75),...,10^5. The matched adaptation repeats selection from the matured residual history of each release and refits using its selected value and all matured history. Factor changes the covariance estimator, retaining the same regularization grid and historical split permutations. The archived R_check.csv contains 17 source checks on the original 14-window grid (the first release of each stream plus three selected diagnostics). All choose the same penalty; maximum scale-adjusted prediction discrepancy is 4.28e-10. These checks support implementation fidelity; they do not establish that extending or retuning the author grid would leave the ranking unchanged.

## Robust linear reconciliation

The matched test uses 36 calibration dates and 72 scored dates on 22 configurations (six datasets, same two backbones, old Labour late window alone, run 42). Source commit 3b041f41579c6b34e8fe4db70c9c2510e59ada37. For coherent calibration observations, the least-squares normal equations give the same minimum for every PSD precision. The recorded solution uses the minimum-norm continuation. The coherent-projection continuation agrees on fitted values. The maximum normalized normal-equation residual was 1.20e-9; the diagnostic checks one bootstrap member for PSD and is distinct from rerunning the upstream solver on all 22 streams. The archived native Australian births check, using newly fitted Prophet, source alpha=1 and an independent equivalent SDP solver, recorded relative metrics 0.96976/0.97552 versus published 0.968/0.973.

Of 22 calibration matrices, 18 had deficient column rank. For Wiki2, the proportion ||Xtest(I-Xcal+ Xcal)||F/||Xtest||F ranged from 0.0553 to 0.3026. ECommerce had rank 14 of 14 in all four matrices. Both continuations gave the same ECommerce predictions up to rounding, with high error under both. Thus calibration-to-scoring extrapolation is relevant, but the observed poor performance cannot generally be attributed to an unidentified null-space continuation. When the minimum-norm target receives CPOR protection, its paired RMSE falls by an average of 82.014% (median 90.568%) across the 12 dataset/backbone groups. This number pertains to this target, split, metric and calibration budget.
