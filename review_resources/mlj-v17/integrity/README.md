# Independent trajectory-certificate replay

From the extracted numerical supplement run `python v17/integrity/reviewer.py` with Python 3.11 and NumPy. This writes fresh per-trajectory margins and a protocol summary under `v17/integrity/replayed/`. Alternatively, when supplied these three scripts beside each other, run `python reviewer.py --or2 ESM_2.zip --out replayed` against the unopened OR2. All temporary extraction is confined to the output directory. The replay requires the v15 paths and v16 endpoint differences already inside OR2. The 189 trajectory inputs and the sidecars are each checked against their recorded SHA-256. It reconstructs the archived evidence, starting with the released arrays, without retraining the forecasters.

The calculation does not import the original primal/dual, scoring or transfer routines. It treats stored binary values as dyadic rationals. For each date and node it evaluates the candidate primal path and exact excess-loss envelope and settles the actual directional error. Integer square roots give 90-fractional-bit bounds for the Full and feasible directional scores.

The certificate lower bound is recomputed by evaluating affine minorants on the two-group coefficient cube. Each stored objective cut proposes directions across dates. The code forms its own directions and checks the exact norm at each node, then floors multiplier weights to 62 fractional bits with their sum at most one. For a constraint at time t the code constructs the tangent using historical squared-error residuals; for its current scalar support it checks the chosen k does not exceed the reference b. A nonnegative weighted sum of these minorants bounds the optimum below. Minimizing this affine lower function on the cube only requires summing its negative coefficients after the forced first anchor. The accumulation uses arbitrary-precision signed integers and a shared denominator. This validates certificate decisions independently of the original outward-rounded floating-point arithmetic; tiny changes in the certified margins are expected.

The literal comparison substitutes the second direction formed from both physical endpoints. For the transfer to fully reconstructed witness releases the reported allowance bound additionally deducts the worst-case objective change and the multiplier-weighted constraint changes. This replay derives that deduction from the supplied endpoint differences and verifies it does not exceed the v16 reported upper bound. Original feasible witnesses on the reverse cases certify the endpoint-closed comparison only. The signs of all forward classifications are checked separately for all three representations. Margin units follow the original dataset. The relative physical margin divides by that case's Full score; pooled extrema in native units do not measure cross-dataset effect size.

`geometry.py` checks all three exact envelope inequalities in the text example and the alternative-witness construction. `geometry.tex` supplies the argument. No fitted model or optimizer is needed.
