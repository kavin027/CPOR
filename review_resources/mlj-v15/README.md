# CPOR fixed-partition trajectory certificates and November release replay

Use 64-bit CPython 3.11. Unzip the small CPOR_Two_Examples.zip and run **python reproduce.py** from the extracted directory. The command creates its own environment, installs NumPy and verifies both DLinear early windows (run 1). An internet connection to a Python wheel index is needed on first use. No paper repository, optimizer, original training data or fitted checkpoint is required. For the full data use the v15 folder in the public repository, or the v15 folder in Online Resource 2.

* **python reproduce.py --all** recomputes all 189 objective intervals, the 189 historical Full and fixed-group scores and both separation counts.
* **python reproduce.py --aemo** also regenerates the two November AEMO releases (Full and AdaptiveTwo) for all 18 streams. It installs the numerical stack listed in requirements-aemo.txt. The script starts each rule with zero credit, obtains available credit by settling matured labels and reserving pending worst-case losses, chooses a prediction, checks its release and computes its score. The reference is persistence, the PIR input uses linear filling and a label matures at issue t+3. Frozen timings are in aemo/times.csv; replay time depends on hardware.
* In an existing compatible environment, python verify.py --all and python replay_aemo.py run the checks directly. Hashes cover the inputs and scripts. A replay reports both binary equality and the largest absolute difference; any tolerance for floating-point reproduction applies only to comparison with stored values. The nodewise protection tests use exact arithmetic.

## Obtaining each trajectory

inputs.csv has one row per dataset, backbone, run and early/late/continuous protocol. The download column is relative to this folder. All 189 numerical optimization inputs and witnesses are supplied directly. Each row also gives the original archive paths and SHA-256 for context, the coherent PIR target, the full release and the fixed two-group release. The window folders use single and the continuous folders use carry. These hashes identify the original larger forecast caches in the author's archive; requests for original caches should cite the four hashes. The compact files suffice to reproduce the reported certificates. The two-example ZIP contains only its named trajectories. For every other row use [the full version](https://github.com/kavin027/CPOR/tree/mlj-v15-20261115/review_resources/mlj-v15).

The compact file supplies the exact signed reference residual, the two affine directions, the intercept needed for the scalar protection test, the two published-path residual sequences and the S9 per-node lower-bound moments. Signed integer arrays are little-endian bytes with a shared binary exponent. The last direction closes on the stored candidate. For the protection test we retain the smaller of the reference and a dyadic cap C chosen so that (R-1) C exceeds the sum of both absolute directions. Whenever this substitution changes the intercept, every coefficient in the box stays in the quadratic branch, and candidate nonnegativity holds over the entire box. Thus it preserves both constraints and all residuals. r_float and D_float reproduce the floating support directions used to construct the bound. The checker evaluates the resulting cuts against the outward-rounded exact data. It rebuilds the older S9 score from per-node moments; OR2/fixed_groups provides the original S9 relaxation generator.

A path supplies the upper endpoint. Every stored coefficient is checked against its box, the releases are checked as binary rationals, and each residual norm is rounded upward. Nonnegative multipliers, support points and objective norm-ball witnesses supply the lower endpoint; the checker rounds down the affine minimum over the box. Full below the lower endpoint excludes every hindsight path in this fixed class. An upper endpoint below Full exhibits one better feasible path. The positive Wiki2 and reverse ECommerce examples exercise both branches. No causal forecaster has access to those future realized labels at issue time.


If you have the original hash-matched caches, run python check_sources.py /path/to/archive, where that directory contains streams/. This reconstructs the exact affine directions, objective residuals, envelope branch coverage and the two observed score inputs for each compact file. It needs only NumPy.
